## Начало работы

### Установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/uzhulpa/online-store_backend
   ```
2. Перейдите в папку проекта:
   ```bash
   cd online-store_backend
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```

---

## Использование

Запуск в обычном режиме:
```bash
npm run start
```

Запуск в режиме разработки:
```bash
npm run start:dev
```
